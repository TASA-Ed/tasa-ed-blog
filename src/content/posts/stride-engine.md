各位好，Stride 是一个免费的**开源**跨平台 C# 游戏引擎，它适用于 2D 和 3D 游戏，以及在桌面和 VR 上运行的任何其他交互式内容。

## 特点

### 游戏工作室

Stride 附带一个强大的工具链，使您能够直观、高效地创建、管理和修改游戏的所有资产。

该编辑器套件可简化和自动化常见的开发工作流程。其嵌套的预制件和原型系统可沿所有编辑器和资源扩展。

Stride Game Studio 的设计也使其可以轻松扩展。

### 高级图形

有了 Stride，无需成为渲染专家即可制作出精美的游戏。引擎会为您完成工作，因此您可以专注于重要的事情。

Stride 的 PBR 材质、光照探针、后期效果、多线程和下一代图形 API 支持可提供具有出色性能的逼真图形。

灵活的管道、可访问的低级 API 和可自定义的着色器让您可以根据需要调整渲染。

### 可靠的引擎

无论您是独立游戏还是 3A 级游戏，Stride 都能让您专注于自己的想法，而不是技术问题。

它带有一整套专门用于编辑游戏每个部分的模块。每个模块都是开箱即用的，并集成到引擎中。

使用着色器和脚本热重载的现代 C# 脚本可让您构建原型并快速迭代。

### VR 准备

Stride 的集群前向渲染及其多重采样抗锯齿功能使其成为 VR 的理想选择。启用 VR 就像单击一下一样简单。

Stride 为每台设备使用单一 API，原生支持 Oculus 和 HTC Vive。

Stride 的 **HRTF 双耳音频**极大地改善了 VR 沉浸感。

### C# 脚本

Stride 中的 C# 脚本利用 C# 12 和 .NET 8 框架中的最新语言功能，为开发人员提供用于创建游戏逻辑和交互性的尖端工具。

随着 Stride 集成到 .NET 生态系统中，开发人员可以访问丰富的库和资源，以增强他们的游戏开发体验。

通过利用 C# 12 和 .NET 8，Stride 使开发人员能够采用现代编程概念和技术，从而生成可靠、高效且可维护的游戏代码。

## 常见问题解答

如需更多问答，请访问[常见问题解答页面](https://www.stride3d.net/faq/)。

### 我可以为哪些平台使用 Stride 制作应用程序？

Stride 目前支持 **Windows**。对 **Android**、**iOS**、**Linux** 和 **macOS** 的支持处于试验状态。Stride 还支持大多数流行的 VR 设备。

### 在哪里可以了解 Stride 功能？

请参阅 [Stride 功能页面](https://www.stride3d.net/features/)、[Stride 文档](https://doc.stride3d.net/latest/en/manual/)、[Stride 博客](https://www.stride3d.net/blog/)和 [Stride 发行说明](https://doc.stride3d.net/latest/en/releasenotes/)。如果您找不到要查找的内容，请在 [Stride GitHub 讨论中](https://github.com/stride3d/stride/discussions)提问。

### 如果我修改了 Stride/Xenko，用修改后的 Stride/Xenko 制作游戏，那么我制作的游戏是否必须开源？

不。Xenko 3.x 和 Stride 4+ 由 MIT 许可证覆盖。

### 使用 Stride 可以制作哪些应用程序？

Stride 是开源的、高度模块化的，并且用途广泛。您可以使用它来制作 PC 和 VR 游戏，或用作训练模拟或建筑和工程软件等应用程序的高端渲染引擎。

### 我使用 Stride 制作的内容归我所有吗？

是的。您使用 Stride 制作的所有内容均归您所有。
